# SportsMate AI

**Developed by: Jahnavi**

## Project Description

SportsMate AI is an AI-powered sports equipment shopping assistant built using Python, LangChain, and the Groq API. It helps users explore sports products, check sample prices, view available colors, and receive product recommendations based on their preferences and budget.

## Features

- Conversational shopping assistance.
- Sports equipment information across multiple categories.
- Product prices and available color details.
- Budget-based product recommendations.
- English and Telugu language support.
- Conversation history during the current session.
- Product search using a LangChain agent.
- Excel-based chatbot response testing (if implemented).

## How to Run

1. Open the project notebook in Google Colab.
2. Install the required Python packages.
3. Add your Groq API key to Google Colab Secrets using the name `AgenticAI`.
4. Execute the notebook cells in order.
5. Start interacting with SportsMate AI.

## Important Note

The product catalog currently uses sample product information, prices, and colors for demonstration. It does not represent live store inventory or real-time market prices.
